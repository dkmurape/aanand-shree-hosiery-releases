# Anand Shree Hosiery POS — public releases

This repository contains the public installers and release notes for **Anand Shree Hosiery POS**.

The application source code is kept in a separate private repository.

## Download

Open the [latest release](https://github.com/dkmurape/aanand-shree-hosiery-releases/releases/latest) and choose the file for your computer:

| Platform | File |
| --- | --- |
| Windows | `...-win-x64-setup.exe` (recommended) or `...-win-x64-portable.exe` |
| Linux | `...-linux-x86_64.AppImage` or `...-linux-amd64.deb` |
| macOS | `...-mac-arm64.dmg` |

Close the POS before installing an update. Shop data, backups and the offline license are preserved.
